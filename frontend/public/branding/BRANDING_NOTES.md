# Internal POI Dashboard branding assets

Suggested uses:
- login-hero.webp: login/SSO landing page, form on the dark left side.
- brand-panorama.webp: optional welcome/portal banner, not over the operational map.
- welcome-illustration.webp: optional onboarding or mode-selection page.
- brand-sunset.webp: alternate welcome/login illustration; center has a large logo.
- brand-india-map.webp: alternate splash/onboarding visual; logo in center.

These images were converted from user-provided PNGs into optimized WebP files.
Their original content was preserved. Avoid loading all five on a single page.

Path when unpacked from the repository root:
frontend/public/branding/

Vite public URLs: /branding/login-hero.webp, etc.

Confirm that the organization permits use of any MapmyIndia trademark/brand assets before public deployment or committing to a public repository.
